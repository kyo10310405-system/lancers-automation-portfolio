# FlowPilot - GAS実行手順

このデモは **実際にGoogleスプレッドシート上で動くGoogle Apps Script** と、ブラウザのCSV処理デモを同梱しています。実在する顧客情報は含みません。

## 1. スプレッドシートで動かす

1. Googleスプレッドシートを新規作成します。
2. シート名を **`sales_raw`** に変更します。
3. 「ファイル > インポート」から同梱の `sample_sales.csv` を読み込みます。文字コードは UTF-8 です。
4. 「拡張機能 > Apps Script」を開きます。
5. 既存の `コード.gs` に同梱の `Code.gs` 全文を貼り付けて保存します。
6. 関数リストから `runAutomation` を選び、「実行」を押してGoogleの権限確認を完了します。
7. スプレッドシートに `sales_report`（担当者別集計）と `automation_log`（実行履歴）が作成されます。
8. スプレッドシートを再読み込みすると「FlowPilot 自動化」メニューが表示されます。

## 2. 毎日の実行

「FlowPilot 自動化 > ② 毎日9時の自動実行を設定」でトリガーを作成できます。Apps Scriptの時間主導トリガーは **9時ちょうど** を保証しません。スクリプトプロジェクトのタイムゾーンを **Asia/Tokyo** に設定してください。

「③ 自動実行を解除」で停止します。重複したトリガーは除去してから設定する設計です。

## 3. メール通知

`Code.gs` の `FLOWPILOT.NOTIFY_EMAIL` に送信先メールアドレスを設定すると、集計結果が更新された場合にだけメール通知します。**初期状態は空欄で送信しません。** GASのメール送信回数・実行時間などのクォータには注意してください。

## 4. データと制限

- 必須列：`日付`, `担当者`, `案件名`, `金額`, `ステータス`
- 日付：`YYYY-MM-DD` または `YYYY/MM/DD`
- ステータス：`成約`, `見込み`, `失注`
- `成約` だけを担当者別に集計。完全一致する重複レコードを除外。
- 不正な行は集計から除外され、ログに件数が記録されます。
- 収益や通知結果はサンプルであり、実業務の実績ではありません。
- メール送信には認証が必要です。APIキーやパスワードをソースにハードコードしないでください。

## 5. 実装上の注意

Googleフォームや外部サービスの仕様変更、GASのクォータ、ログに残す情報の機密性、トリガー実行ユーザーの権限、運用中の異常通知などは、本番導入前に個別設計が必要です。
